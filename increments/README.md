# Implemented Increments

The `increments/` directory contains implementation history and work selected
for immediate execution. Every completed document here describes behavior that
exists in the repository and points to its evidence.

Dormant future capabilities do not belong here. They live as atomic proposals
in [`ideas/`](../ideas/README.md) until selected for detailed planning and
implementation. A stalled increment returns to `ideas/`; a completed increment
is rewritten as implementation evidence and retained here.
