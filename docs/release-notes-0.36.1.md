# ZAM 0.36.1 — The essentials first

ZAM can connect models, devices, databases and assistants, but most learners do
not need to see that control room every time they change an everyday setting.
Desktop and Mobile now open Settings with the essentials in view and keep the
operator controls one deliberate step away.

## A calmer Settings screen

- **Simple is the default.** Learning mode, daily workload, the ordinary cloud
  AI connection, appearance or reminders, learner profile and updates stay in
  the first view.
- **Advanced is still complete.** Local-AI setup, speech routing, server and
  database plumbing, device pairing, agent integration and fine-grained limits
  remain available behind a clear Simple / Advanced switch.
- **Safety does not disappear with complexity.** Database status and errors,
  backup actions and setup recovery remain visible when a learner needs them.
  The view preference stays on that device; it does not change anyone's shared
  learning settings.

## Learning mode where learners look for it

- **Native Desktop now exposes the learner's mode directly.** Flash, guided
  answer and feedback, and answer variation can be selected in Settings without
  opening an assistant panel or a terminal.
- **The in-review Flash / AI choice stays in sync.** A change is persisted for
  the learner and immediately updates the active card without discarding a
  typed answer or fetching another card.

## Switches that work from the keyboard

- **One tab stop, then arrow keys.** The Simple / Advanced and Flash / AI
  controls now behave like the radio groups they announce to assistive
  technology. Arrow keys move and select, with Home and End jumping to either
  edge.
- **Focus survives the save.** A successful mode change returns to the selected
  option; a failed save restores the option that is still checked. Keyboard
  navigation no longer drops the learner into the answer field, and pressing
  Home or End on the current edge does not write the same setting again.

Existing libraries, cards, review history, database schema and FSRS schedules
are unchanged.
