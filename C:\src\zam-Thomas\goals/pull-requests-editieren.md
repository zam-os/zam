### Breakdown
- **Bestandteile eines Pull Requests** — Die bearbeitbaren Bereiche eines Pull Requests wie Titel, Beschreibung und Metadaten unterscheiden.
- **Titel und Beschreibung bearbeiten** — Titel und Beschreibung eines Pull Requests in GitHub ändern und die Änderungen speichern.
- **Markdown-Aufgabenlisten verwenden** — Aufgabenlisten mit Markdown-Checkboxen in der Beschreibung erstellen und ihren Status bearbeiten.
- **Änderungen speichern und prüfen** — Erkennen, ob eine Bearbeitung gespeichert wurde, und die aktualisierte Pull-Request-Ansicht kontrollieren.
- **Berechtigungen und Bearbeitungsrechte** — Verstehen, wer einen Pull Request bearbeiten darf und welche Rechte dafür erforderlich sind.
