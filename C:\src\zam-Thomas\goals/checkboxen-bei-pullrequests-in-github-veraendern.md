## Description
Ich sehe offene Punkte eines Pull Requests und erledige die Tests. Jetzt möchte ich die Checkbox checken. Die Änderung soll auch gespeichert werden. Wann passiert das? Was muss ich tun?
### Breakdown
- **Checkboxen erkennen** — Du kannst offene Aufgaben-Checkboxen in der Beschreibung eines Pull Requests von Checkboxen in Kommentaren oder anderen Bereichen unterscheiden.
- **Markdown-Checkboxen verstehen** — Du weißt, dass `[ ]` eine offene und `[x]` eine erledigte Checkbox darstellt.
- **Pull-Request bearbeiten** — Du kannst die Beschreibung des Pull Requests im Bearbeitungsmodus öffnen und die passende Checkbox als erledigt markieren.
- **Änderung speichern** — Du kannst die Bearbeitung mit der Schaltfläche zum Aktualisieren des Pull Requests speichern, statt nur den Text im Eingabefeld zu ändern.
- **Änderung überprüfen** — Du kannst prüfen, ob die Checkbox nach dem Speichern im Pull Request als erledigt angezeigt wird.
