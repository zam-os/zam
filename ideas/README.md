# Ideas

This directory is the backlog for capabilities that are valuable but not
implemented. Each file describes one independently promotable capability.

## Rules

1. Keep one capability per file.
2. Link only hard prerequisites under `Depends on`.
3. Do not expand an idea into a detailed implementation plan here.
4. Promote an idea to `increments/` only when it is selected for immediate,
   detailed planning and implementation.
5. Move a stalled increment back to `ideas/`; do not leave dormant plans in
   `increments/`.
6. Remove the idea after the implemented increment records the shipped result.
