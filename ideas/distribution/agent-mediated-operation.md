# Agent-Mediated, Console-Free Operation

## Outcome

Non-developers operate ZAM end to end through an AI agent and the desktop GUI
without typing a shell command. The agent translates natural-language intent into
the ZAM bridge for setup, identity, storage choice, sessions, reviews, and token
maintenance, and the GUI surfaces the same actions visually. The terminal becomes
optional rather than the required front door. Builds on the default-mode install
and the provisioned default agent from Increment 12.

## Depends on

- None.

## Promote when

A default-mode install and a provisioned default agent exist, and the bridge
covers the full onboarding-to-review loop reliably enough for an agent to drive
it unattended.
