# Hermes Desktop as an Alternative Bundled Agent

## Outcome

Offer Hermes Desktop (Nous Research) as a second, GUI-first option for the
agent that ZAM's setup can provision, alongside the default (opencode). Hermes
is attractive for non-developers: a native desktop app with built-in
multi-provider support, including local OpenAI-compatible endpoints — which
dovetails with the prepaid cloud LLM provider idea. Adopt it once its native
Apple Silicon and Windows-on-ARM builds and official distribution channel are
verified, and a scriptable interface exists to drive ZAM sessions.

## Depends on

- None.

## Promote when

Hermes ships verified native arm64 builds for macOS and Windows-on-ARM from an
official Nous Research source, and exposes a stable headless/scriptable surface
that can drive the ZAM bridge.
